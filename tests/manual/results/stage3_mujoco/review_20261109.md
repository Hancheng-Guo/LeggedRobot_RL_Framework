## 本轮发现并修复

1. 手工训练验收脚本强制读取可选的 termination/terrain_bounds。当前业务配置未开启该 term，原脚本会报 KeyError。改为读取 state/ground_valid，补充关闭可选终止时的回归测试；未重新开启业务配置。
2. 坡面边缘回落的部分碰撞三角形同时存在 x/y 梯度，可能达到采样斜率的 √2 倍。例如 max_slope=0.3、runtime_seed=42、patch_id=12 时，原实现可超过约定上限。采样 x 斜率增加 1/√2 上界，确保实际碰撞三角形梯度模长不超过 max_slope×difficulty；新增矩形/非整除网格及不同难度的回归测试。
3. 地形生成规则改变，分配状态版本升至 3，拒绝版本 1/2，避免旧分配状态按新规则恢复成另一张地形。
4. README 及阶段说明中的示例默认启用 TerrainBounds 已过期，改为与当前未启用的业务配置一致。

## 后续坡形与参数语义修订（2026-11-09）

按用户后续要求，正 slope 在中央出生矩形外沿 ±x、±y 四向均抬升，负 slope 四向均降低；出生矩形及最外圈仍为零高度。离开出生区的距离改为 max(abs(x)-safe_x, abs(y)-safe_y)，高度改为 slope×run。

max_slope 明确表示 slope 采样系数的幅度上限，不再表示碰撞三角形的实际总坡度。因此取消此前的 1/√2 缩放，采样范围为 [-max_slope×difficulty, +max_slope×difficulty)。上述早期“坡度上界修复”记录是历史语义，当前以本节及 README 为准。分配状态版本升至 4，拒绝版本 1/2/3。
