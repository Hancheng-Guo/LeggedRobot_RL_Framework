## 二、总目标与第一版范围

在现有框架中加入可配置、可复现、支持向量环境的随机几何地形：

1. MuJoCo 与 Isaac Sim 使用相同的配置语义和公共几何描述，允许采用不同的碰撞表示。
2. 不同环境可以分配不同地形，回合重置与地形更换解耦。
3. 离地高度相关的观测、奖励和终止条件使用局部地面参照，保留需要世界坐标或机身参照的信号。
4. 固定种子、恢复训练、评估和回放能够重现地形及其分配。
5. 未启用地形功能时，保持当前平地运行与训练行为，不要求额外的非平地后端能力。
6. 地形策略属于 task，碰撞表示和物理操作属于 simulator，训练代码不依赖引擎专有对象。

第一版基础范围支持 `plane`、`slope`、`rough`。摩擦随机化和台阶的进展见第十章，两个扩展独立于阶段 4 验收。

公共高度网格只表达每个 `(x, y)` 对应一个高度的表面，暂不覆盖洞穴、悬挑和多层桥面。

### 3.2 配置结构

地形配置属于 task YAML：

```yaml
randomization_manager_config:
  terms:
    terrain:
      category:
        type: Weighted
        params:
          values:
            plane: {weight: 1}
            slope: {weight: 1, max_slope: 0.15}
            rough: {weight: 1, max_height: 0.04}
      difficulty:
        type: Uniform
        params:
          values: [0.25, 0.6, 1.0]
      patch_size: [4, 4]
      resolution: 0.1
      spawn_size: [1.5, 1.2]
      spawn_margin: 0.5
      resample_patch: false
      resample_spawn: false
      seed: null
```

- category 支持 Fixed、Weighted、Curriculum；difficulty 支持 Fixed、Uniform、Curriculum。
- 两轴的 Fixed 都只允许一个候选，不接受 params.value；省略 category 使用 plane，省略 difficulty 使用 1.0。
- 只有 Weighted category 接受 weight，默认 1，必须为有限正数；Fixed/Curriculum 拒绝显式 weight。
- 候选与参数分别属于两个子 term；同一课程实例联合规划，不同实例分别学习。
- 尺寸、分辨率、出生区、种子及网格／出生重采样开关属于 terrain。
- 配置通过 to_mapping() 导出；内部默认权重不会泄漏到 Fixed/Curriculum 配置。
- 旧 sampling/types/difficulty_levels 和旧 value 写法不再接受；simulator YAML 只保存模型和物理参数。

### 3.3 三种地形的含义

**`plane`**：高度相对原地面为零。单独配置平地时沿用原有无限平面；与其他类型混合配置时，使用有限高度场，全部顶点高度为零。

**`slope`**：中央出生区保持平坦，区外沿 ±x、±y 四个方向同号起伏。正系数均抬升，负系数均降低，外边缘回到零高度，与外围平地衔接。采样范围为 `[-max_slope × difficulty, +max_slope × difficulty)`；不除以 `√2`，该参数限制采样系数，不限制双轴合成后的实际坡度。

**`rough`**：出生区及其保护网格保持平坦，其他有效内部顶点在 `[-max_height × difficulty, +max_height × difficulty)` 内独立均匀采样，最外圈顶点为零。网格通过三角形连接，实际局部坡度不受 `max_slope` 限制。

### 3.4 初始化流程

1. `_prepare_task → task.prepare(config=...)`：解析配置并声明资源需求，不提前构建 manager。
2. `_build_simulator`：取得 task 的资源需求，构建后端碰撞布局。
3. `_build_task`：在 `ModelContext` 可用后构建各 manager。
4. `task.bind(simulator=...)`：绑定、测量和校验，不生成或应用初始地形。

空资源需求返回 `{}`；只有已使用资源需要释放时，才传入显式 `None`。

### 3.5 重置、更换与回滚

完整和局部 reset 采用同一事务：

```python
task.before_simulator_reset(env_ids)
simulator.reset(env_ids)
task.after_simulator_reset(env_ids)
task.reset(env_ids)
# 构建状态与观测，成功后提交
task.commit_simulator_reset(env_ids)
```

- pre-reset 先结算旧回合并分配候选条件，再应用地形；command 消费同一分配。
- 首次使用、类型／难度变化或显式换 patch 时，为选中环境生成新地形。
- `Fixed` 普通 reset 复用；`Uniform` 每次抽样，`Curriculum` 读取课程分配。条件相同且未请求换 patch 时不重新生成、不重复上传。
- 相同难度请求不会重新生成；后端重新绑定后应用缓存网格。
- 出生位置默认由 patch 种子确定；可用 `resample_spawn` 或显式请求独立更换。
- 物理、出生、command 及观测初始化全部成功后，才提交候选分配。
- 应用地形、物理 reset、出生、command 或观测初始化失败时，恢复物理、地形、课程、任务缓冲及采样进度，保留请求，不改变未选环境。

普通 reset 仍保留回滚快照，因此复用地形不等于消除全部 reset 开销。

### 3.6 地面信号与边界

`SimulatorState` 包含四个可选字段：

| 字段 | 含义 |
|---|---|
| `base_ground_height` | 机身位置下方的世界地面高度 |
| `foot_ground_heights` | 各足 geom 中心位置下方的世界地面高度 |
| `ground_valid` | 机身和全部足端是否具有有效地面高度 |
| `terrain_in_bounds` | 机身和全部足端是否仍在随机地形区域内 |

MuJoCo 使用有限随机区域加外围平地，外围每侧延伸 **1000 米**，不覆盖内部负高度地形。

- 高度场内部查询高度场，外围查询真实平地。
- 离开随机区域后，地面信号仍然有效。
- `TerrainBounds` 可选择越出随机区域即终止，当前 ANYmal 示例未启用。
- 超出整个地面覆盖范围的直接高度查询返回 `NaN`；状态采集将对应环境标记为无效，并屏蔽无定义的地面相对高度信号。
- 不把所有查询异常都解释为越界，也不自动添加终止策略。

### 3.7 可复现性与数据约定

- 长度单位为米；网格行对应 y，列对应 x。
- 单元沿左下至右上的对角线划分三角形，碰撞和高度查询使用相同划分。
- `resolution` 是最大单元尺寸，每轴使用 `ceil(length / resolution)` 个等长单元。
- 高度查询输入世界 xy，形状为 `[环境, 采样点, 2]`，输出同设备、同 dtype 的世界高度。
- 地形专用 seed 为 `null` 时跟随 runtime seed；指定整数时独立固定地形随机性。
- 地形生成使用版本化无状态随机标签，不消费训练随机流。
- 类型顺序影响加权抽样区间，配置比较和恢复校验必须保留这一含义。
- 地形分配状态版本为 **6**，正式 terrain 检查点外层版本为 **2**；保存类型／难度、代数、原始环境身份、采样／出生计数和待处理请求。恢复首次 reset 重建当前场景，后续 reset 继续采样；不自动迁移旧格式。

### 3.8 播放与索引命名

- 播放、相机跟随、渲染、viewer 锁和上传判断以 `simulator.playback_env_index` 为来源。
- `VectorEnv.playback_env_index` 仅转发。
- 克隆模板和读取同构模型公共信息的索引不与播放索引耦合。
- `env_ids`：允许 `None` 的入口参数，`None` 表示全部环境。
- `env_ids_tensor`：明确的 Tensor 索引。
- `env_ids_list/env_ids_tuple`：列表或元组形式。
- `env_id`：单个环境编号。

### 3.9 已提交的课程与采样约定

以下约定已由 `6c71784` 实现，后续接入 terrain 时沿用：

- 课程实例名与算法 `type` 分开；一个实例对应一个联合空间，同算法可以创建多个独立实例。
- 引用同一实例的维度联合分配；不同实例分别统计奖励、更新概率和采样。不再使用 `group`。
- 空间描述由提供方 manager 生成，task 收集，CurriculumManager 合并与构建；课程算法不导入具体 command 或 terrain 实现。
- command 使用 `Uniform` 独立采样，或通过 `Curriculum`／`SymmetricCurriculum` 显式引用课程实例。command 只读取分配，在区间内生成实际命令。
- 连续维度与数值离散候选的构建能力已具备；离散类型编号的领域含义由提供方解释。
- `max_cells` 已取消用户配置，空间构建采用内部固定容量保护。
- `finalize_episodes()` 结算旧回合，`resample()` 分配新条件；二者已提前到物理 reset 前，失败时一并回滚。
- `learning_progress` 和 `probabilities` 统一在回合结算后导出快照；评估时输出冻结状态。
- Stage 通过显式 `revision_metric`、`validity_metric` 读取通用指标，不访问课程 manager 或推导课程专用字段。
- 不兼容旧算法名称、旧 command 类型、group 配置或旧 Stage 开关；旧检查点格式不做自动迁移。

参考：[课程与 command 验收记录](../../tests/manual/results/command_curriculum/README.md)。其中的 JSON 为对应源码版本的历史验证记录，最新实现以当前提交为准。

### 扩展 A：独立摩擦随机化

**状态：MuJoCo 和 Isaac Sim 均已通过摩擦物理、状态恢复及渲染验收。**

**安排：**阶段 4 完成后先在 MuJoCo 实现，再随阶段 5 的后端接入工作实现 Isaac 对应能力。

**目标：**在不改变地形几何的前提下，可配置、可复现地随机化接触摩擦。

#### 开发内容

1. 作为独立的 `friction` randomization term，能够与 `terrain` 组合，也能够单独用于平地。
2. 按环境采样一个 `params.factors` 倍率，目标足地接触系数等于原接触系数乘一次倍率。MuJoCo 缩放地面、外围平地与足端各自的初始滑动摩擦系数。Isaac 根据该目标反推足端材质，保留共享地面。每次 reset 都从初始值计算。
3. 定义共享参数及各后端映射，说明接触双方参数如何形成实际接触属性；不把相同配置数值直接当成两后端等效物理行为。
4. 明确首次构建、普通 reset、地形或区域切换时的采样与应用规则，不隐式要求每次 reset 重建几何。
5. 独立均匀采样使用确定性随机源，课程采样支持与地形、命令联合分配。保存倍率和采样进度，接入阶段 4 的检查点与固定场景评估机制。
6. 验证局部更新隔离。reset 失败时，恢复所选环境的摩擦系数、接触与动力学数据以及采样状态。
7. 提供参数说明及可复跑物理验证，区分摩擦效应与策略训练效果。

#### 完成标准

- 不启用时保留原接触属性；单独启用和与三种地形组合时均能正常工作。
- 固定种子、局部 reset 和中断恢复能够重现摩擦采样与分配。
- 通过受控的滑动物体或斜面等用例，验证摩擦变化确实作用于接触；外围平地符合已定义的作用范围。
